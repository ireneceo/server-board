# /복원 — 백업으로 되돌리기 (kit 공용판)

1. 묻기(선택 질문): 대상 개발/운영 · 코드+DB / DB만 / 코드만.
2. 보여 주기: 최근 백업 목록 · `git log --oneline -10`.
3. **{{OWNER}} 승인 뒤에만** 실행:
   - DB: **지금 DB 를 먼저 백업**(pre_restore_시각) → 복원 → 재시작.
   - 코드: `git stash` → `git reset --hard <번호>` → 빌드 → 재시작.
   - 운영: {{OWNER}} 의 마지막 확인을 한 번 더 받은 뒤에만.
4. 확인: 상태 확인 · 주요 표 개수.
같은 서버의 다른 솔루션은 건드리지 않는다.
