# /개발시작 — 오늘 일 시작 (kit 공용판)

값은 이 솔루션 `CLAUDE.md` 의 «개발 명령 설정» 절에서 읽는다. 없으면 «없음» 으로 보고 건너뛴다.

1. **다른 작업 확인**: `git status --short` · `git diff --stat`. 다른 방·도구가 고치다 둔 변경은 덮어쓰지 않는다. 내가 할 일과 겹치면 멈추고 보고.
2. **작업기록 읽기**: 작업기록 파일 전체.
3. **들어온 문의·피드백 확인**(«운영 문의 읽기» 가 있을 때만, 읽기 전용): 원문을 직접 읽는다(요약 믿지 않기). 항목마다 이미 고쳐졌는지(코드·데이터·배포 기록) 먼저 확인 → «이미 해결 / 할 일 / 결정 필요» 로 나눈다. 확인한 번호·시각을 작업기록에 적는다. 운영 접속이 막히면 우회하지 않고 보고.
4. **문서·구조**: «꼭 읽을 문서» 전부 · «구조 보기».
5. **보고** — 첫 줄 상태(✅/⏸/❌). 문의 표(번호·요약·판정·근거) 먼저, 그다음:
   - 진행 중인 작업이 있으면: 요약 + 이어서 할 일
   - «다음 확정 작업» 이 있으면: 그 일 + 참고 경로
   - 둘 다 없으면: «지시 대기». **새 일을 스스로 만들지 않는다**(«후속 후보» 는 메모로만 인용).

규칙: «뭘 할까요?» 같은 열린 질문 금지(선택지+권고로). 고객 답장·운영 쓰기는 {{OWNER}} 지시 없이 하지 않는다(초안까지만).
