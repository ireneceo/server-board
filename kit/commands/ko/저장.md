# /저장 — 지금 상황을 작업기록에 (kit 공용판)

코드는 건드리지 않고 작업기록만 다시 쓴다(새 방이 읽고 이어갈 수 있게).
1. 작업기록 다시 쓰기: 마지막 업데이트(날짜·시각) · 진행 중인 작업(어디까지·바로 다음 한 걸음) · 답 기다림(무엇을·왜·답 오면 할 일 — 제목 한 줄에 요점) · 완료된 작업 · 다음 확정 작업 · 후속 후보.
2. git 상태 적기: 바뀐 파일 · 커밋 안 된 것 · 마지막 커밋 번호. (커밋은 하지 않는다)
3. 보고: 저장 위치 · 다섯 줄 요약 · 이어 하는 말(«작업기록 읽고 이어서 해줘»).
비밀번호·열쇠는 작업기록에 쓰지 않는다. 지난 «답 기다림» 은 제목에 «(이전)» 을 붙인다.
