# /save — write the current situation to the notes file (kit command)

Don't touch code; only rewrite the notes file (so a new room can read it and continue).
1. Rewrite the notes file: last update (date, time) · In progress (how far, the very next step) · Waiting for answer (what · why · what to do when answered — the point in the heading line) · Done · Next up · Ideas.
2. Git state: changed files · uncommitted · last commit id. (Don't commit.)
3. Report: where it's saved · five-line summary · the phrase to resume with ("read the notes and continue").
Never write passwords or keys into the notes file. Add "(previous)" to the heading of old "Waiting for answer" sections.
