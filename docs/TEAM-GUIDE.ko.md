# 팀원·디자이너 안내

> 이 상황판에서 일을 요청하는 팀원·디자이너용. 서버 관리 지식은 필요 없습니다.

## 들어오기
1. 최종 컨펌자에게 받은 **로그인 링크**를 엽니다(24시간·한 번). 비밀번호(10자 이상)를 정하면 바로 들어와집니다.
2. 다음부터는 상황판 주소를 열고 **아이디 + 비밀번호**로 로그인합니다. 아이디 = 서버 계정 이름(없으면 사설망 로그인 이메일).
3. 들어오는 길(SSH 통로 · Tailscale)은 최종 컨펌자가 알려 준 것을 씁니다. 길이 달라도 같은 아이디·같은 역할입니다.
4. 화면 위 **👤 이름 · 역할** 에서 로그아웃 · 비밀번호 바꾸기.
- 48시간 쓰지 않거나 7일이 지나면 다시 로그인합니다.
- 비밀번호를 5번 틀리면 15분 막힙니다. 잊었으면 최종 컨펌자에게 새 링크를 받으세요.

## 할 수 있는 일
- 맡은 솔루션만 보입니다.
- **일 요청 = «제안»** 으로 올라갑니다. 최종 컨펌자가 «하기 · 고쳐서 하기 · 안 하기» 를 정한 뒤 시작합니다(설정에 따라 다를 수 있음).
- 내가 제안해 시작된 작업방의 질문에는 내가 답할 수 있습니다(설정 «팀원이 답하는 방»).
- 배포·설정·지우기·팀 관리는 최종 컨펌자만 합니다.
- 디자이너: 지금은 팀원과 같습니다. 화면 단순 수정(문구·색·간격·배치)을 바로 진행하는 기능은 다음 단계에서 열립니다.

## 요청 잘 쓰는 법
- 무엇을 · 왜 · 어느 화면(주소) · 어떻게 되면 끝인지를 한 덩어리로.
- 화면 주소는 그대로 붙여 넣기.

## 하지 말 것
- **비밀번호·열쇠·고객 개인정보·운영 데이터를 요청 글에 넣지 않습니다.** 요청 글은 AI 작업방에 그대로 전달됩니다.
- 내 로그인을 다른 사람과 같이 쓰지 않습니다. 사람마다 따로 받습니다.
