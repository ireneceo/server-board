# 서비스 안내: 무료로 직접, 또는 맡기기

[English →](SERVICES.md)

서버 상황판은 **무료이고, 앞으로도 무료**입니다. 잠긴 유료 기능도, 체험 기간도 없습니다.
SSH 열쇠·권한·정기 점검 설정에 시간을 쓰기보다 내 서비스에 집중하고 싶다면, 서버 쪽 일은 워프로랩(WOR-PRO Lab)이 대신 해 드립니다.

## 무엇이 들어 있나 (무료판·구축 모두 같은 프로그램)

| 묶음 | 내용 |
|---|---|
| 한눈 보기 | 맨 위 «지금 답하거나 볼 것» · 프로젝트마다 작업방 상태(일하는 중 / 답 기다림 / 끝남 / 멈춤)·마지막 보고·확인할 링크 |
| 대화·답하기 | 작업방 대화를 채팅처럼 보고 브라우저에서 답함 · «AI 와 상의» |
| 내가 할 일 분리 | sudo·외부 서비스 설정처럼 주인만 할 수 있는 일은 순서·링크·복사할 명령이 붙은 카드로 따로 · «다 했어요» 면 AI 가 이어서 |
| 알아서 굴러가기 | 프로젝트마다 고치는 방 하나(대기열) · 끊긴 방 자동 이어하기 · 정기 점검 |
| 안전한 배포 | AI 는 배포를 «준비»·«막기» 만, 실제 배포는 상황판이 등록된 명령으로 · 배포 전 «끝난 일 확인 완료» · 배포 중엔 다른 일이 비켜 줌 |
| 시험 계정으로 열기 | 보고의 확인 링크를 그 역할 시험 계정으로 로그인된 채 엶 |
| 팀·보안 | 개인 로그인(인증 앱·예비 코드) · 역할(최종 컨펌자·팀원·디자이너·보기만) · 중요한 버튼 30분 재확인 · 터미널 비상 복구 · 개발 사이트 로그인 관문(선택) |
| 서버 지킴이 | 메모리 자리표(빌드가 겹쳐 서버가 멈추지 않게) · AI 로그인 끊김을 상황판에서 다시 로그인 · 로그인 열쇠 지킴이 · Claude Code 버전이 바뀌면 스스로 점검 |
| 접속 | 인터넷에 열지 않음 — Tailscale 사설망 또는 SSH 통로 · 휴대폰 홈 화면 앱 · 서버 터미널 메뉴(`dev`) |

## 네 가지 방법

### 1 · 무료 제공: 직접 설치해서 쓰는 기본 프로그램

- 이 저장소 전부: 상황판·터미널 메뉴·대기열·자동 이어하기·정기 점검·설치 프롬프트·확인 스크립트
- GitHub Issues 로 코드 버그 문의
- **이런 분께:** 리눅스·SSH·Claude Code 가 익숙한 개발자

[설치 안내 →](INSTALL.ko.md)

### 2 · 유료 구축: 고객 서버에 설치하고 AI 연결, 접근 권한, 자동화 설정까지 구성

**고객의** 서버에 설치하고, 보통 가장 오래 걸리는 부분을 구성해 드립니다.

- 상황판 설치 · PM2 로 상시 실행 · 재부팅 뒤 자동 시작
- **AI 연결:** Claude Code 설치 · 로그인은 *고객이 직접* 본인 Anthropic 계정으로(저희는 Claude 계정 정보를 받지 않습니다) · 권한 모드 설정 · 프로젝트 폴더 허락
- **접근 권한:** 고객(과 팀원)의 SSH 열쇠, root 가 아닌 사용자, 노트북 **및 휴대폰** 상황판 통로
- **자동화:** 프로젝트 등록 · 공용 작업 규칙 · 개발 명령(개발시작·개발완료·검증·배포)에 실제 빌드·재시작·상태 확인 값 채우기 · 정기 점검 일정
- **서버 관리자(sudo) 일:** 재부팅 자동 시작·Tailscale·방화벽·사용자 systemd 유지를 [운영 절차서 9절](OPERATIONS.ko.md#9-서버-관리자sudo만-할-수-있는-일--한곳에-모음) 목록대로 함께(sudo 를 주시면 대신) 처리
- **메모리 자리표:** 빌드·시험 명령을 자리표로 감싸고 자리표 없는 빌드를 막는 검사까지 켬(서버 메모리에 맞춘 값)
- 인수 설명(화면 공유) + 서면 보고: 무엇을 설정했는지 · 쓰는 법 · 되돌리는 법
- **이런 분께:** 구조를 배우지 않고 이번 주 안에 돌아가게 하고 싶은 대표·팀

[구축 의뢰 →](https://care.wor-pro.com/inquiry.php?utm_source=github&utm_medium=docs&utm_campaign=server-board&lang=ko&plan=setup&src=services-setup)

### 3 · 유료 맞춤 작업: 고객 서비스에 맞는 배포·백업·장애 대응 작업 추가

구축 위에 **고객의** 기술 구성에 맞춘 절차를 더합니다.

- 관문 있는 배포 스크립트: 빌드 확인 → 먼저 백업 → 안전한 DB 변경 → 상태 확인 → 명령 하나로 되돌리기
- 백업(코드+DB)·보관 기간·**실제로 해 본** 복원
- 장애 대응: 문제가 생기면 작업방이 먼저 볼 것, 알림, 대응 순서서
- **시험 계정으로 열기** 연결: 프로젝트에 개발서버 전용 로그인 경로 하나(`kit/DEV-LOGIN.md` 계약)와 역할별 시험 계정
- **개발 사이트 로그인 관문:** 프로젝트마다 예외 경로(결제·택배 웹훅, 앱 연결 파일, 서버 안 자동 시험) 조사 → nginx 연결 → 켜고 «로그인 없이 막힘 / 로그인하면 열림 / 휴대폰에서 열림» 확인
- **상황판 배포 버튼:** 배포 명령·시험 배포·되돌리기 명령을 등록하고 실제로 한 번 돌려 봄
- 서비스 전용 명령·검사(결제·회사별 데이터 분리·보호 파일 등)
- **이런 분께:** 실사용자가 있어 잘못된 배포나 데이터 손실이 곧 손해인 서비스

[맞춤 작업 의뢰 →](https://care.wor-pro.com/inquiry.php?utm_source=github&utm_medium=docs&utm_campaign=server-board&lang=ko&plan=custom&src=services-custom)

### 4 · 월 유지관리: 서버와 자동화가 제대로 작동하는지 점검하고 개선

- 매달 점검: 상황판·정기 점검·작업방 정상 여부, 실패한 실행, 멈춘 방, 디스크·메모리, 로그 용량, 백업
- Claude Code 업데이트 대응: `verify.sh` 실행, 바뀐 부분 고치기
- 팀이 실제로 쓰는 방식에 맞춰 규칙·명령 개선
- 짧은 월간 보고
- **이런 분께:** 직접 또는 저희와 설치한 뒤, 계속 잘 돌아가기를 원하는 분

## 나에게 맞는 것은?

| 상황 | 시작 |
|---|---|
| 리눅스를 알고 도구만 필요 | **무료** |
| 무료로 설치해 봤는데 막힘(열쇠·권한·PM2) | **구축**: 어디서 막혔는지 적어 주세요 |
| 이번 주 안에 내 서버에서, 휴대폰까지 되게 | **구축** |
| 유료 사용자가 있어 배포·백업이 안전해야 함 | **구축 + 맞춤 작업** |
| 돌아가고 있고, Claude Code 업데이트를 챙기기 싫음 | **월 유지관리** |

## 의뢰는 이렇게 진행됩니다

1. [care.wor-pro.com](https://care.wor-pro.com/inquiry.php?utm_source=github&utm_medium=docs&utm_campaign=server-board&lang=ko&src=services-how) 에 **의뢰 남기기**(아래 항목을 적어 주시면 빠릅니다)
2. **질문 회신 또는 짧은 통화**로 범위 맞추기
3. 범위에 맞춘 **견적**(구축·맞춤 작업은 정액, 유지관리는 월 단위)
4. **임시 접근:** 고객 서버 사용자에 *저희* 공개 열쇠를 넣어 주시면 됩니다. 비밀번호·개인 열쇠는 절대 받지 않습니다
5. **작업 + 확인:** `verify.sh` «✘ 0개» · 실제 시험 방 · 휴대폰 통로까지 시험
6. **인수 보고** 뒤 **저희 열쇠를 지웁니다**(유지관리 계약이면 유지)

### 의뢰할 때 적어 주시면 좋은 것

- 호스팅 업체·OS(예: «가비아/AWS, Ubuntu 24.04»)·메모리
- 프로젝트 수와 기술 구성(예: «Node API + React, 워드프레스 사이트»)
- Claude Code 를 이미 쓰는지, 어떤 요금제인지
- 작업방에 맡기고 싶은 일(기능 개발·버그 수정·정기 점검·배포 준비 …)
- 접속할 사람(혼자 / 팀 N명)과 기기(맥·윈도우·아이폰·안드로이드)
- 상황판·보고 언어(한국어/영어)와 시간대

## 접근에 대한 약속

- Claude Code 는 **고객의** Anthropic 계정으로 돕니다. 계정을 재판매하거나 공유하지 않습니다.
- 작업에 필요한 것만 읽고, 비밀값을 출력하지 않으며, 바꾼 파일 목록을 모두 남깁니다.
- 상황판은 비공개(`127.0.0.1` + Tailscale 사설망·SSH 통로) 그대로. 인터넷에 열지 않습니다.
- 고객의 분명한 승인 없이 운영 배포·운영 데이터 변경을 하지 않습니다.

## 자주 묻는 질문

**무료판은 기능이 제한되나요?** 아니요. 고객 서버에 설치하는 것과 같은 프로그램입니다.
**Claude 구독이 필요한가요?** 네. Claude Code 는 고객 본인의 Anthropic 계정·요금제가 필요합니다.
**윈도우·맥 서버도 되나요?** 상황판은 리눅스 서버에서 돕니다. 접속하는 *컴퓨터*는 맥·윈도우·리눅스, 휴대폰은 아이폰·안드로이드 모두 됩니다.
**사이트가 웹호스팅(root 없음·Node 없음)에 있어요.** 상황판은 거기서 돌지 않지만, 작은 리눅스 작업 서버를 두고 Claude 가 거기서 만들고 시험한 뒤 `/배포` 로 호스팅에 올리게 구성해 드립니다. root 는 어디서도 필요 없습니다 — [어디서 돌아가나](../README.ko.md#어디서-돌아가나)
**이미 운영 중인 서버에 설치해도 되나요?** 네. 설치는 파일을 더하기만 하고 기존 앱을 재시작하지 않습니다([설치 기준](AI-SETUP-PROMPT.ko.md#0-설치-기준-설치-내내-지킨다)은 저희가 지키는 기준과 같습니다).
**가격은요?** 프로젝트 수와 자동화 범위에 따라 다릅니다. 의뢰를 남기시면 견적으로 답드립니다.
